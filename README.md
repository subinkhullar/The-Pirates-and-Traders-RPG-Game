# 🏴‍☠️⚓ The Pirates and Traders RPG Game by Subin Khullar 😎

A feature-rich standalone browser-based pirate trading, naval combat, exploration, and empire-building role-playing game built entirely using HTML5, CSS3, and Vanilla JavaScript.

Travel across dangerous seas, command powerful ships, build merchant empires, become a feared pirate lord, rise through the Royal Navy, discover ancient treasures, recruit legendary crews, and shape the destiny of the world's oceans.

**The Pirates and Traders RPG Game by Subin Khullar 😎** is a deep sandbox RPG set during the great age of sail.

Players begin as a penniless sailor and gradually rise to become:

- Merchant Emperor
- Pirate King

- Legendary Explorer

# 📚 Story

The year is 1687.

The seas are in turmoil.

Europe's greatest empires battle for dominance.

Merchant guilds control vast fortunes.

Pirates terrorize trade routes.

The Royal Navies hunt anyone who challenges imperial authority.

Legends tell of the lost Tideborn Empire, an ancient civilization destroyed centuries ago.

Before its fall, five sacred relics were hidden throughout the world.

Together they reveal the location of:

## The Crown of the Endless Sea

The greatest treasure ever known.

After surviving a devastating naval battle, the player receives a fragment of a mysterious map from a dying navigator.

This is the beginning of a journey that can lead to:

- Wealth
- Glory
- Freedom
- Power
- Legend

# ⚙️ Installation Instructions

## Option 1: Local Play

1. Download all generated files.

Files should be:

- index.html
- styles.css
- app.js
- service-worker.js
- manifest.json

2. Place them in the same folder.

3. Open:

index.html

in a modern browser.

Recommended:

- Microsoft Edge
- Google Chrome
- Brave
- Firefox

---

## Option 2: Local Web Server

Run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

---

## Option 3: GitHub Pages

Upload files to GitHub Pages for hosting.

The game functions entirely client-side.
